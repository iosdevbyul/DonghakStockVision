# R1 주가 방향 예측 성능 감사

2026-11-25 KST · **PARTIAL**. 기존 모델의 점수와 실제 시장 결과를 연결했다. 같은 표본의 학습 사전확률 기준선은 평가 36건 중 35건에서 더 정확했다. 역사적 연구의 행별 점수와 독립 미래 성능은 확인할 수 없었다.

## 1. 조사 범위와 원본 자산

PR #253 병합 시점의 R1 범위에서, 실제 KRX 자료에 기반한 2개 코호트 × 3개 정책의 역사적 연구와 Selection Reliability readout을 조사했다. 역사적 실험 72건에는 고유 실험 및 체크포인트 해시 66개가 있었다. 각 기록에는 개발 fold 4개가 있어 집계 288건을 조회했다. 사용된 추정기는 LogisticRegression, RandomForest, HistGradientBoosting이다. H1/H5/H20 계약과 46개 특징, 7개 마스크, 14개 후보 프로필을 가진 기존 카탈로그를 유지했다. 다종목 연구의 liblinear 격리 규칙이 적용됐다.

AnalysisStore, Experiment Memory, 원본 결과 및 체크포인트의 식별자를 재사용했다. 주가 연결에는 원본 개발 fold의 최종 체크포인트 대신, 해당 체크포인트로 **이미 평가한** 2026-10-06~11-13 readout의 보존 점수를 사용했다. 원래 fold별 추정기와 행별 점수는 보존 저장소에서 찾을 수 없었다. 마지막 전체 학습 체크포인트는 그 fold의 평가 기간을 포함할 수 있어 해당 fold의 예측을 재생하는 데 사용할 수 없다. 이번 감사는 신규 피팅, Historical Replay, 모델 추론을 각각 0회 수행했다.

Phase B/C/D의 실제 선택과 결과는 보존 보고서 및 세션에서 확인했다. Phase B 최종 보고서의 콘텐츠 식별자와 Phase C의 첫 실행 창 이후 보고서 식별자가 별도 PIN과 일치했다. Phase C의 15건은 두 실행 창 합산이며, 첫 창 보고서는 7건을 담고 있다. Phase D의 최종 Publication과 실행 창 readback은 별도 파일 SHA-256과 일치했다. Research Lab은 기존 집계 조회에 사용하며 R1 원본 행은 로컬 CLI에서 조회한다. 3개 모델이 등록된 H1/H5/H20 Shadow의 최신 보존 Publication에는 예측과 비교가 0건이었다. 별도 레거시 저널의 현행 헤드에는 역사적 재생 예측 10건(평가 5, 대기 5)이 있었고 독립 미래 증거는 0건이었다.

### 동일 표본 기준선

36개 원본 모델 그룹 평가 중 학습 사전확률 기준선보다 정확도와 Brier가 각각 개선된 경우는 1건씩이었다. AP가 정의된 24건 중 17건에서 AP가 더 높았고, Balanced Accuracy는 24건 중 12건에서 높고 2건에서 같았다. 코호트 2 H1 adaptive pooled LogisticRegression은 AP 0.6081 대 0.4158, Brier 0.2396 대 0.2481, 정확도 57/101 대 59/101로 지표별 결과가 엇갈렸다. 개발 fold에서 학습 사전확률·다수 클래스·모멘텀 중 최고 AP를 이긴 수는 H1 52/96, H5 74/96, H20 65/96이다. 각 fold 안에서 같은 대상에 계산한 기준선이며, 반복 사용한 fold와 동일 해시는 여러 집계에 나타난다.

## 3. 관측한 실패와 연구 비교

- **H5 상승 오탐.** 코호트 1 adaptive heldout LogisticRegression은 상승 예측 52건 중 42건 오탐, 코호트 2 adaptive heldout RandomForest는 49건 중 42건 오탐이었다. 0.50 이상 0.60 미만 점수 구간에서는 각각 34/40과 42/49가 오답이었다. 전체 라벨은 각각 상승 19/83, 12/84였고 비중첩 앵커는 각각 4개다. 로컬 보고서의 원본 실험 접두어 `0749dbce9f90`, `062781842aa3`와 `outcome == "incorrect"`로 사례를 조회할 수 있다.
- **종목·국면별 차이.** 같은 코호트 2 H5 84행에 대해, 같은 RandomForest 프로필의 daily/legacy 마스크 모델이 모두 37/84를 맞혔다. 보존된 종목별 고변동성 구간에서 오답은 8/37 대 19/37, 정상 변동성에서는 38/46 대 27/46이었다. 두 모델은 각각 적중한 종목과 기간도 달랐다. 해당 실험 접두어는 `062781842aa3`, `ef86f61be32b`다. 이 국면 분류는 종목 입력 특징 기반이다. 공식 시장 국면은 확인할 수 없었고 표본은 반복 실패 판정 기준에 미달한다.
- **원본 사례의 추적.** 코호트 1 H1 adaptive pooled RandomForest(`01b3c7684db8`)는 첫 평가 입력일에 실제 하락을 각각 정답과 오답으로 분류했다. 점수는 0.49236과 0.50055였다. 로컬 보고서에서 종목, 정확한 거래 세션, 검증된 기준·목표 종가, 실제 수익률과 원본 평가 ID를 확인할 수 있다.

## 4. R2 가설

1. **H5 상승 오탐 감소.** 실험 `0749dbce9f90`, `062781842aa3`의 42/52와 42/49 상승 오탐을 근거로, 독립적으로 예약한 교정 구간에서 class-weight를 유지한 사전확률 보정을 검증한다. 같은 모델과 같은 라벨 모집단에서 원래 0.5 분류, 학습 사전확률, 보정 후보를 비교한다. 두 코호트에서 거짓 양성률이 최소 10%p 감소하고 상승 재현율 손실이 5%p 이하이며 Brier가 악화되지 않을 것으로 예상한다. 기존 표본 기준을 충족한 별도 평가에서 조건 중 하나라도 실패하면 가설을 기각한다.
2. **변동성별 마스크 효과.** 실험 `062781842aa3`, `ef86f61be32b`의 동일 H5 평가에서 고변동성 오답은 8/37 대 19/37로 차이가 있었고, 정상 변동성에서는 반대였다. 동일 RandomForest 프로필·학습 종목·기간·임계값에서 기존 daily와 legacy 마스크만 바꾼다. 사전 등록한 고변동성 구간에서 daily의 오답률이 최소 10%p 낮고, 전체 Brier와 정상 변동성 Balanced Accuracy가 악화되지 않는다는 가설이다. 기존 표본 기준을 만족한 별도 fold와 두 코호트에서 효과가 재현되지 않으면 기각한다.

두 가설은 노출된 readout의 관측을 바탕으로 하며 R1에서 검증 실험을 수행하지 않았다. 최신 식별자 전체, 평가 ID와 행은 로컬 보고서에 있다.

## 5. 로컬 재현 및 조회

기존 **Selection Reliability** 루트와 별도 보관한 plan PIN 파일을 입력한다. 새 보고서 디렉터리와 새 PIN 디렉터리는 원본 디렉터리 밖에 각각 만든다. 보고서와 PIN은 비공개로 저장된다.

```sh
umask 077
dsv autonomous-research prediction-audit \
  --root "$SELECTION_ROOT" --plan-pin-file "$SELECTION_PLAN_PIN_FILE" \
  --report "$PRIVATE_R1_REPORT" --pins-root "$PRIVATE_R1_PINS"
```

특정 모델과 기간의 실제 오답을 조회하려면 다음과 같이 필터링한다. `models[].metrics`와 `baselines`에 동일 분모의 비교 결과가 있고, `breakdown`에는 종목·월·방향·국면·점수 구간 집계가 있다. `development[].folds`에는 원본 평가 범위·집계·예측 다이제스트가 있다.

```sh
jq --arg cohort historical-cohort1 --arg id 01b3c7684db8 '
  .readout[] | select(.cohort == $cohort and .horizon == 1)
  | .models.original_group_selection | select(.experiment_id | startswith($id))
  | {experiment_id, metrics, baselines, errors: [.rows[] | select(.outcome == "incorrect")]}
' "$PRIVATE_R1_REPORT"
```

Phase B의 원본 조회 경로는 기존 `dsv memory-research report`다. Phase C/D에는 `dsv memory-research campaign-report`와 각 승인 창에 보존한 비교 readback이 있다. Shadow는 기존 `dsv direction-shadow report`와 승인된 Publication으로 따로 조회한다. R1에서 새 외부 게시를 하지 않았다.

최종 로컬 감사 명령의 경과 시간은 26.24초였다. 모델 사용료와 신규 시장 데이터 요청 비용은 0이었다. 원본 Phase B/C/D의 실행 비용은 기존 보고서에 있다.

## 6. 무결성과 남은 근거

- **충족** — 실제 데이터 및 자산 조사, 72개 원본 실험 및 288개 fold 집계, 원본 보고서와 체크포인트 해시 확인, 후속 평가의 종목별 보존 점수와 실제 가격 연결, 동일 분모 기준선, 재현 명령과 R2 가설.
- **부분 충족** — 원래 개발 fold의 개별 점수·추정기가 보존되지 않아 전체 연구의 행별 원본 결과를 복원할 수 없다. 평가 종목별 제외 사유와 시장 전체의 공식 국면도 확인 불가다. 후속 평가에서 나타난 실패는 독립 비중첩 앵커 기준을 충족하지 못했다.
- **근거 부족** — 일관된 연구 개선과 독립 미래 성능. Phase C/D의 승인 범위 및 데이터 노출을 유지하며 108개 Phase D 미실행 슬롯은 실행하지 않았다.
- **보호 검증** — 원본 연구 DB와 보고서, plan PIN, 체크포인트, readout을 읽기 전용으로 확인했다. 운영 DB의 전체 파일은 원래 스냅샷 이후 바뀌었다. 원래 전체 파일 PIN은 그대로 보존했으며, 고정된 28개 원본 배치마다 manifest, 원본 응답 해시, 정규화 행을 다시 검증했다. Final Test와 2026-Q3 평가 결과는 조회 대상에서 제외했다. 신규 KRX 요청, Gemma 호출, 외부 배포, 승인 변경은 0건이다.
