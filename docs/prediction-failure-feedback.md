### 연구 A · H5 상승 오탐

R1과 같은 모델 설정을 더 이른 보호 범위의 학습 표본에 새로 피팅했다. R1 모델의 옛 체크포인트는 R2 평가 날짜를 포함하는 기간을 학습했으므로 고정 0.5 대조군의 추론에는 이른 시점의 새 체크포인트를 사용했다. 사전 등록한 교정은 별도 기간의 이진 로그 손실에서 기울기 1을 유지한 채 로그 오즈 절편 한 개를 맞춘다. 기존 학습 사전확률도 같은 평가 행에서 비교했다. FPR은 FP/(FP+TN), FDR은 FP/(TP+FP)다.

## Feedback 및 보호

- 실제 모델 피팅 5회, 교정기 피팅 2회, 평가 모델 추론 5회, 교정용 추론 2회가 있었다. 코호트 2의 원설정 모델은 연구 B Daily와 설정·학습 집합이 일치해 실행 내에서 한 번만 피팅했다. 신규 KRX, LLM 호출, Historical Replay, R1 점수 재사용은 0회다. 특징·가격과 라벨은 허용된 원본 평가 자료로 확인했다.
- 첫 실행은 10.95초 후 평가 스냅샷의 nullable 품질 메타데이터를 읽는 오류로 멈췄다. 그 전에 모델 5개와 교정기 2개가 고정됐다. 초기 실행은 보존했다. 수정된 판독 코드로 같은 표본·방법·판정 규칙을 재등록하고 모든 고정 아티팩트를 해시 검증해 재사용했다. 복구 평가 11.45초, 두 작업자 관측 경과시간 합계 22.40초, 최대 RSS 264,984 KiB, 추가 사용료 0이었다.
- 기존 AnalysisStore에서 `failure_feedback` → 가설 → R1 오답 → 원래 피팅 및 교정기 → 같은 평가 행과 전후 성능을 연결했다. 5개의 H5 평가용 체크포인트, 두 교정기, 914개의 실제 기준·목표 종가/수익률/라벨/점수·정오답 행을 보존했다. 각 코호트 후보 804행에서 중립/제외/미확정은 17/211/24 및 14/416/12건이다.
- R1의 원본 Plan·Source·Dataset PIN과 체크포인트를 별도 보관했다. 학습·교정·평가의 SQL 투영은 각각 등록 날짜 및 종목만 가져왔다. Q3와 Final Test는 평가·연구 입력에서 제외했다. 기존 PIT, 성능 및 실행 승인 상태는 모두 false다.

## 로컬 조회와 재현

비공개 요청은 `prediction_failure_feedback_request_v1` 버전과 `selection_root`, `selection_plan_pin_file`, `r1_report`, `r1_report_pin_file`을 사용한다. `request.pin`은 원래 canonical JSON 다이제스트다. 최초 실행 루트는 Selection Reliability 루트의 새 형제 디렉터리이며 Plan PIN은 별도 디렉터리에 보관한다. 이미 고정됐으나 평가만 중단된 실행을 복구할 때 새 요청에 원본 `root`, `plan_pin_file`을 담은 `fit_recovery`를 추가한다. 같은 계획과 동일한 런타임의 고정 모델·교정기만 재사용할 수 있다.

```sh
umask 077
dsv autonomous-research failure-feedback-register --root "$R2_ROOT" \
  --pins-root "$R2_PINS" --request "$R2_REQUEST" --request-pin-file "$R2_REQUEST_PIN_FILE"
dsv autonomous-research failure-feedback-run --root "$R2_ROOT" \
  --plan-pin-file "$R2_PINS/plan.pin"
dsv autonomous-research failure-feedback-report --root "$R2_ROOT" \
  --plan-pin-file "$R2_PINS/plan.pin" --report "$R2_ROOT/report.json"
jq '.result.cases[] | {cohort, fixes: [.rows[] | select(
  .correct.original == false and .correct.calibrated == true)]}' "$R2_ROOT/report.json"
```

`.result.origins[].failure_rows`에서 원래 오답을, `.result.cases[].rows`에서 같은 R2 평가 행의 기존·후속 점수를 조회한다. `.result.hypotheses`, `.result.decisions`, `.calibrators`에서 가설 ID와 평가 결과 및 교정 아티팩트를 확인한다. 기존 Research Lab Publication에는 기존 집계가 남고, 비공개 R2 행과 모델은 로컬 조회로 제공한다.

## 후속 연구에 남기는 판단

교정 기간의 상승 비율은 학습보다 높았다. 그 분포에 맞춘 보정은 두 코호트에서 상승 전환과 함께 FPR을 늘렸다. 다음 연구에는 별도 교정 기간에서 FPR과 Recall 목표를 함께 고정한 단일 대조를 검토할 근거가 생겼다. 마스크 연구에는 고변동성·정상 변동성의 비중첩 앵커와 양 클래스 수를 먼저 확보한 뒤, 동일 모델과 동일 평가 계약의 비교를 반복할 근거가 생겼다. 이 문서는 R3 실행 승인을 포함하지 않는다.
